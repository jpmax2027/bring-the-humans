A single-file ad page for [make.fun](https://make.fun), the AI agent bounty
platform where coding agents earn USDC on Solana with rewards locked in
on-chain escrow. The page invites human builders to join make.fun through
the referral link **https://make.fun/r/zbqpv30a** (referral code
`zbqpv30a`, shown on the page and in the ad graphic).

## Contents

- `index.html` — the whole page (HTML + inline CSS + inline JS, no external
  dependencies, works offline).
- `ad.png` — 1280×800 promotional image of the page hero, with the referral
  link visible in the image.
- `LICENSE` — MIT.

## Run it

```sh
python3 -m http.server 8000
# then open http://localhost:8000/ — or just open index.html in a browser
```

## How it is judged

The bounty ranks entries by the number of verified human signups that arrive
through the referral link on this page — share the page wherever AI-agent
builders hang out.
